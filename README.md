# Manhwa Discord Cleaner

بوت مستقل لتبييض صفحات المانهوا وإرسال مجلد Google Drive. بنيته Python فقط؛ لا يحتاج Expo أو Qwen أو MongoDB أو خادم HTTP خارجي.

## التشغيل

```bash
python3 -m venv .venv
.venv/bin/pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install -e '.[test]'
cp .env.example .env
# ضع بيانات Discord وGoogle Drive في .env
.venv/bin/manhwa-cleaner prepare-models
.venv/bin/manhwa-cleaner doctor
.venv/bin/manhwa-cleaner bot
```

يحتاج البوت صلاحيات View Channel وSend Messages وUse Application Commands. استخدم رابط دعوة بتصاريح `bot` و`applications.commands`. لا يحتاج Message Content Intent. ضع `DISCORD_GUILD_ID` لتسجيل الأوامر فورًا في خادم معين؛ تسجيل الأوامر العام قد يستغرق بعض الوقت.

* `/clean attachment:` صورة PNG/JPEG/WebP أو ZIP فصل، أو `/clean drive_url:` رابط ملف/مجلد Drive. لا تجمع المصدرين. ترتيب صفحات الفصل طبيعي: 1، 2، 10.
* `mode: dialogue` يقبل فقاعات ذات داخل مستوٍ ومغلق بصورة محافظة. الفقاعات المفتوحة والخلفيات المعقدة قد تحتاج مراجعة.
* `mode: all-text` يمسح النص المكتشف بما فيه المؤثرات والعلامات المائية. اختره فقط إذا أردت ذلك.
* `/status job_id:` حالة محفوظة، حتى بعد إعادة تشغيل البوت.
* `/cancel job_id:` إلغاء مهمة ما زالت في الطابور.
* `/retry_delivery job_id:` إعادة رفع نتيجة محفوظة دون إعادة تبييض الفصل.

## ضمانات التنفيذ وحدود الجودة

1. Comic Text Detector ONNX يعمل على نوافذ 1024×1024 متداخلة 256 بكسل في المحورين. الصفحة لا تُصغّر كاملة، فلا يختفي النص الصغير في الصور الطويلة.
2. صندوق الكشف يقيد خريطة تقسيم النص البكسلية. وضع الحوار يضيف حارسًا محافظًا للفقاعة؛ لا يُستنتج قناع واسع من صندوق Qwen.
3. الفقاعات المغلقة المستوية تُملأ بلون خلفيتها، والفقاعات الناعمة تستخدم Telea لترميم التدرج محليًا. المناطق المعقدة والقناع اليدوي يستخدمان Anime-Manga Big-LaMa على نوافذ بسياق إضافي. كل جزء من النتيجة يكتب مرة واحدة، والبكسلات خارج القناع تبقى مطابقة للمصدر RGB بعد اتجاه EXIF وتركيب الشفافية على الأبيض.
4. فشل النموذج يفشل المهمة. لا يُرسل الأصل بوصفه نتيجة ناجحة. عدم الكشف، أو النص المرفوض، أو نسبة نص متبقٍ فوق 3% ينتج `needs_review`.
5. إعادة الكشف مقياس آلي محدود؛ ليست إثباتًا بأن كل حرف اختفى، ولا تكشف نصًا فات الكاشف قبل وبعد المعالجة. راجع overlay والقناع والصورة كاملة.
6. الحارس المحافظ ليس مصنفًا دلاليًا مضمونًا: قد يرفض فقاعات ملونة/مفتوحة، وقد يقبل لوحة نص مستوية. يلزم توسيع مجموعة التقييم قبل اعتماد الجودة لكل فصل.

كل صفحة ينتج عنها `cleaned.png` و`mask.png` و`overlay.png` و`report.json`. مجلد التسليم يحتوي كذلك `chapter-report.json` وأسماء المصادر. رابط النتيجة قابل للقراءة لمن يملك الرابط.

## الطابور والتسليم

SQLite WAL يحتفظ بالمهام. عامل واحد فقط بوساطة قفل عملية، مع طابور 12 مهمة ومهمة نشطة واحدة للمستخدم. يعاد استئناف المهام بعد انقطاع العامل وتُعاد استخدام الصفحات المكتملة. يفصل فشل التبييض عن فشل Drive. الملف المرفوع يدعم upload resumable وتُفحص أسماء الملفات قبل إعادة التسليم. إشعار الإنجاز يرسل للقناة ليعمل بعد انتهاء صلاحية تفاعل Discord البالغة 15 دقيقة. يبقى `/status` بديلًا عند فقدان صلاحية إرسال الإشعار.

الحدود: 50MB للمرفق/الصفحة، 40 مليون بكسل للصورة، 100 صفحة للفصل، 300MB للصور المضغوطة إجمالًا. تُرفض ZIP المشفرة أو مسارات traversal أو تجاوز حدود فك الضغط. مجلد Drive يدعم الصور وZIP مباشرة، ولا يتتبع المجلدات الفرعية أو الاختصارات.

الصور والنتائج محفوظة محليًا للاستئناف. تنظيف الأعمال النهائية الأقدم من 7 أيام:

```bash
.venv/bin/manhwa-cleaner purge --days 7
```

هذا لا يحذف مجلد النتائج من Google Drive.

## اختبار محلي دون تشغيل البوت

```bash
.venv/bin/python -m pytest tests -q
.venv/bin/manhwa-cleaner clean page.jpg --output data/result --mode dialogue
# قناع يدوي راجعته أنت، مطابق لأبعاد الصورة بعد الاتجاه:
.venv/bin/manhwa-cleaner clean page.jpg --output data/manual --mask text-mask.png
```

CPU يكفي لكنه أبطأ من GPU. الذاكرة تتأثر بأبعاد الصفحة؛ النماذج محملة مرة واحدة داخل عامل واحد. اضبط `CLEANER_THREADS` حسب موارد الخادم. Docker ومشغل Linux موفران في المستودع. استخدام GPU والتقييم الدلالي للفقاعات يحتاجان تطويرًا لاحقًا.

الاعتمادات المثبتة للاختبار مسجلة في `requirements.lock`. أوزان النماذج ثابتة ببصمات تحقق. لإعادة تقييم صفحة كاملة مع سجل تقدم وكشف أولي محفوظ محليًا: `python scripts/evaluate_page.py page.jpg --output data/evaluation`.

للتشغيل كخدمة دائمة على خادمك: عدّل مسار `/opt/manhwa-discord-cleaner` في `scripts/cleaner.service`، ثم ثبّت ملف الخدمة في systemd. التشغيل في بيئة العمل الحالية يستمر ما دامت البيئة نفسها فعالة؛ ليس استضافة دائمة.
